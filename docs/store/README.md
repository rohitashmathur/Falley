# Falley beta listing pack

Prepared 16 October 2026 for **3.2.0 / version code 7**, package `com.perfgames.falley`. This is an **offline, ad-free beta**. Check `../../BUILD_STATUS.md` for the final artifact and verification result before uploading. No Console entry, public policy page, support address or tester invitation has been created by these files.

The upload guide is [BETA_SUBMISSION.md](../BETA_SUBMISSION.md). Artwork, its alt text, raw-capture provenance and hashes are in [`../../store/assets/manifest.json`](../../store/assets/manifest.json); asset-specific notes are in [`../store-assets.md`](../store-assets.md). These assets are prepared separately and are not evidence of a live listing.

Suggested store category: **Game > Arcade**. Choose only relevant tags actually offered by Console. Keep English (United States) as the initial listing language; additional languages need reviewed translations rather than a claim of localized gameplay.

The title, short description and full description must fit 30, 80 and 4000 characters respectively. A support email is required; a support website is recommended. Both are currently unset. [Play listing and contact requirements](https://support.google.com/googleplay/android-developer/answer/9859152?hl=en)

Asset requirements checked today: icon **512x512**, PNG32 with alpha, at most 1024 KB; feature graphic **1024x500**, JPEG or PNG24 without alpha. Screenshots require at least two, JPEG/PNG24 without alpha, 320–3840 pixels, with the longer side no more than twice the shorter. Games seeking screenshot-based recommendations need at least three actual-gameplay portrait images at **1080x1920** or equivalent landscape images. Prepared phone assets use the portrait format. Preview video is optional. [Play asset specifications](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en)

Store images deliberately show gameplay without graphic deaths. Metadata must suit a general audience even when the game receives an older content rating; do not feature blood, impalement or dismemberment closeups in promotional art. Do not describe this beta as containing ads, online leaderboards, multiplayer or additional locked stages. [Play metadata policy](https://support.google.com/googleplay/android-developer/answer/9898842?hl=en)

Only policy/contact/invitation drafts contain explicit `[[...]]` fields. Those are owner tasks, not valid values for Console, public policy or shipped UI.
