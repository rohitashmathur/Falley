# App access: proposed Console response

Version: 3.2.0 / code 7. No account, password, subscription, purchase, invitation code, network connection or location restriction is required to use the installed app. All six campaign stages and Arcade configurations are available. The Play testing track itself still requires normal tester eligibility; that is separate from access inside the app.

Select the Console option meaning **all functionality is available without special access**. If an instructions field is provided, use:

```text
Falley is an offline game with no login, purchases or ads. All six stages are unlocked.

Open Settings to choose Motion steering on/off. If sensors are absent, use touch. With Motion steering off, swipe left/right to steer against drift; tap the arena or JUMP to jump. Header icons restart or pause the run.

CAMPAIGN starts the selected stage. CHAPTERS lets you select any stage. Land entirely on the target; missing the target is fatal in stages 4–6.

ARCADE / SKIRMISH opens difficulty and hazard choices. At least one hazard must stay enabled. START SURVIVAL begins an endless score/time run.

Settings includes sound, vibration, motion response, blood effects and Privacy Policy. Stylized hazard-specific death effects are part of the game. Blood Effects off suppresses blood; it does not remove all death reactions.
```

Owner check before submission: confirm the final build has the described Privacy Policy entry and both control modes, and that no restricted functionality was introduced. Do not supply a made-up login for a game that has none. [Prepare the app for review](https://support.google.com/googleplay/android-developer/answer/9859455?hl=en)
